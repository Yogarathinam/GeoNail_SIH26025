\section{Executive Summary}

\textbf{GeoNail} is an advanced Internet of Subsurface Things (IoST) geotechnical monitoring platform designed for real-time detection of slope instability, structural micro-displacements, and seismic anomalies in high-risk mining, civil excavation, and landslide-prone environments.

The system integrates high-precision embedded sensor hardware, on-device edge anomaly processing, multi-transport telemetry (BLE, Serial UART, Wi-Fi/MQTT), and a 1:1 real-world scale 3D Web CAD \& Digital Twin Visualizer built on Three.js and React.

\section{Hardware Architecture \& Mechanical Design}

\subsection{Mechanical Form Factor}
The GeoNail housing consists of a heavy-duty industrial-grade sealed polycarbonate shaft housing the electronics core, topped with a locked protective enclosure cap and anchored deep into soil/rock strata via a telescoping magnetic spike anchor.

\begin{itemize}[leftmargin=*]
    \item \textbf{Main Enclosure Body}: Cylindrical shell containing M5Stack Core2 / ESP32-S3 MCU, OLED/IPS display, lithium-polymer power cell, and status transducer.
    \item \textbf{Telescoping Spike Anchor}: Underground anchor embedded directly into stable soil layers. As soil shifts, relative displacement alters internal magnetic field geometry.
    \item \textbf{Locked Top Cap}: Moisture-sealed protective cap housing external antennas and status LEDs.
\end{itemize}

\subsection{Microcontroller \& Sensors}
\begin{itemize}[leftmargin=*]
    \item \textbf{Microcontroller}: ESP32-S3 (Dual-Core Xtensa LX7 @ 240 MHz, 512KB SRAM, 8MB PSRAM).
    \item \textbf{Power Management Unit (PMU)}: AXP192 integrated power controller supporting battery state-of-charge tracking and solar charging.
    \item \textbf{Inertial Measurement Unit (IMU)}: MPU6050 / MPU6886 6-Axis motion sensor (3-axis Accelerometer, 3-axis Gyroscope).
    \item \textbf{Magnetometer / Hall Sensor Array}: Precision magnetic sensing elements to resolve absolute linear displacement of the subterranean anchor rod.
\end{itemize}

\section{Firmware Architecture \& Edge Signal Processing}

The firmware is written in C++ for the Arduino/ESP32 framework (\texttt{GeoNail\_M5Stack\_Firmware.ino}). It executes multi-sensor sampling at 100 Hz with real-time digital filtering and edge anomaly detection.

\subsection{Sensor Fusion \& Orientation Math}
To compute real-time Roll ($\phi$), Pitch ($\theta$), and Yaw ($\psi$) angles without gimbal lock, the firmware implements a Complementary Filter:

\begin{mathbox}
\textbf{Accelerometer Angles:}
\begin{equation}
\phi_{acc} = \arctan2(A_y, A_z) \cdot \frac{180}{\pi}
\end{equation}
\begin{equation}
\theta_{acc} = \arctan2\left(-A_x, \sqrt{A_y^2 + A_z^2}\right) \cdot \frac{180}{\pi}
\end{equation}

\textbf{Complementary Filter Integration:}
\begin{equation}
\phi_t = \alpha \cdot (\phi_{t-1} + G_x \cdot \Delta t) + (1 - \alpha) \cdot \phi_{acc}
\end{equation}
\begin{equation}
\theta_t = \alpha \cdot (\theta_{t-1} + G_y \cdot \Delta t) + (1 - \alpha) \cdot \theta_{acc}
\end{equation}
\begin{equation}
\psi_t = \psi_{t-1} + G_z \cdot \Delta t
\end{equation}
\end{mathbox}

\textit{Where $\alpha = 0.96$ is the filter tuning constant, balancing gyroscope responsiveness with accelerometer low-pass drift suppression.}

\subsection{Subterranean Anchor Displacement Math}
The magnetic flux density $B$ measured along the longitudinal axis varies inverse-proportionally with the insertion distance $d$ of the magnetic spike anchor:

\begin{mathbox}
\begin{equation}
\Delta B = B_{ref} - B_{measured}
\end{equation}
\begin{equation}
d_{mm} = k_m \cdot \sqrt{\frac{1}{\Delta B + \epsilon}} + d_{offset}
\end{equation}
\end{mathbox}

The calibrated constant $k_m$ converts micro-tesla field variations into exact linear displacement in millimeters ($mm$).

\subsection{Edge Anomaly \& Seismic Detection Engine}
\begin{mathbox}
\textbf{Exponential Moving Average (EMA):}
\begin{equation}
\text{EMA}_t = \beta \cdot X_t + (1 - \beta) \cdot \text{EMA}_{t-1}
\end{equation}

\textbf{Root Mean Square Acceleration ($\text{RMS}_{vib}$):}
\begin{equation}
\text{RMS}_{vib} = \sqrt{\frac{1}{N} \sum_{i=1}^N \left(A_{x,i}^2 + A_{y,i}^2 + A_{z,i}^2 - 1.0^2\right)}
\end{equation}
\end{mathbox}

\section{GeoNail OS Web Visualizer Architecture}

The frontend visualizer is a modern React 18 + TypeScript web application (\texttt{sih-3d-visualizer}) powered by Vite, Tailwind CSS, and Three.js / React Three Fiber.

\subsection{3D CAD Viewer Page}
\begin{itemize}[leftmargin=*]
    \item \textbf{Full 3-Axis Reactive Model}: Real-time rotational synchronization driven by live or simulated Pitch, Roll, and Yaw angles.
    \item \textbf{Translucent X-Ray Mode}: Semi-transparent shell (opacity = 0.35), exposing internal battery, M5Stack core board, and magnetometer coils.
    \item \textbf{Locked Cap State}: Standardized fixed state showing locked protective cap securely attached to top shaft.
    \item \textbf{Multi-Preset Camera Control}: Isometric, Top, Front, Side, and Reset Orbit controls.
\end{itemize}

\subsection{1:1 Scale Minefield Digital Twin Page}
\begin{itemize}[leftmargin=*]
    \item \textbf{Real-World Environment}: $800\text{m} \times 600\text{m}$ open-cast mining pit with terraced benches and haul roads.
    \item \textbf{Real-World Scale Reference}: 1:1 scale 3D models of \textbf{CAT 797 Dump Trucks} ($14.8\text{m} \times 9.8\text{m} \times 6.5\text{m}$).
    \item \textbf{Multi-Node Grid Deployment}: Nodes \texttt{GEONAIL-01} to \texttt{GEONAIL-06} positioned along critical slope benches.
    \item \textbf{Subterranean Shear Slice}: Cross-section plane highlighting slip surfaces and bedrock anchor penetration depths.
\end{itemize}
