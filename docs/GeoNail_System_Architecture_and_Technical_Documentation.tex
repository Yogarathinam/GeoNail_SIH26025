\section{Executive Summary \& System Data Pipeline}

\textbf{GeoNail} is a comprehensive Internet of Subsurface Things (IoST) geotechnical monitoring infrastructure engineered to detect real-time ground slope failures, subterranean shear layer slippage, micro-tilts, and seismic shocks in open-cast mines, structural excavations, and landslide-prone transportation corridors.

The platform establishes an end-to-end telemetry loop spanning subsurface physical anchors, edge microcontroller signal processing, multi-transport wireless communications (BLE, USB Serial, Wi-Fi REST/MQTT), and a 1:1 real-world scale 3D Web CAD \& Digital Twin Visualizer built with React 18, TypeScript, and Three.js / React Three Fiber.

\section{Mechanical Form Factor \& Subterranean Anchor Kinematics}

The physical GeoNail device utilizes a two-part telescoping anchoring mechanism designed to isolate surface soil movements from deep-seated bedrock layers.

\subsection{Telescoping Mechanical Form Factor}
\begin{itemize}[leftmargin=*]
    \item \textbf{Outer Casing Shell (\texttt{Piece 1})}: Industrial heavy-duty polycarbonate protective cylinder driven into the upper soil stratum. Contains the M5Stack Core2, battery, display, status LEDs, and top moisture-sealed locking cap.
    \item \textbf{Subterranean Spike Anchor (\texttt{Piece 2})}: Telescoping inner steel shaft tipped with a tungsten carbide anchor head and embedded high-grade Neodymium magnet ($B_0 = 47.60\,\mu\text{T}$). The spike is driven deep into stable bedrock underneath the failure plane.
    \item \textbf{Rotary Locking Mechanism}: The top enclosure cap features Level 2 captive locking grooves. When rotated $+45^\circ$, internal drive tabs lock securely onto shoulder pins, preventing accidental dislodgement under high vibration.
\end{itemize}

\subsection{Magnetic Field Decay \& Displacement Physics}
As ground slope shear occurs, the upper surface soil layer moves relative to the anchored bedrock spike. This relative displacement increases the distance between the magnetometer array inside \texttt{Piece 1} and the magnet embedded in \texttt{Piece 2}:

\begin{mathbox}
\textbf{Magnetic Flux Density Variation ($\Delta B$):}
\begin{equation}
\Delta B = B_0 - B_{\text{current}} \quad [\mu\text{T}]
\end{equation}

\textbf{Subterranean Soil Displacement Calculations:}
\begin{equation}
\Delta d \,(\text{mm}) = \Delta B \times 2.85
\end{equation}
\begin{equation}
\Delta d \,(\text{cm}) = \frac{\Delta d \,(\text{mm})}{10}
\end{equation}
\end{mathbox}

Where baseline $B_0 = 47.60\,\mu\text{T}$ corresponds to the fully seated zero-displacement baseline ($0.0\,\text{mm}$).

\section{Firmware Engine \& Signal Processing (\texttt{GeoNail\_M5Stack\_Firmware.ino})}

The core firmware executes on the ESP32-S3 dual-core microcontroller at a deterministic 100 Hz sampling frequency, processing raw IMU and magnetometer data through complementary digital filters, exponential moving averages, and a multi-stage anomaly state machine.

\subsection{100Hz Sensor Fusion \& Orientation Filtering}
To determine 3-axis orientation without accelerometer high-frequency noise or gyroscope low-frequency drift, the firmware implements a Complementary Filter combining raw gyroscope angular rates with accelerometer gravity vectors:

\begin{mathbox}
\textbf{Accelerometer Tilt Angles:}
\begin{equation}
\phi_{\text{acc}} = \arctan2(A_y, A_z) \cdot \frac{180}{\pi}
\end{equation}
\begin{equation}
\theta_{\text{acc}} = \arctan2\left(-A_x, \sqrt{A_y^2 + A_z^2}\right) \cdot \frac{180}{\pi}
\end{equation}

\textbf{Complementary Filter Equations ($\alpha = 0.96$):}
\begin{equation}
\phi_t = 0.96 \cdot (\phi_{t-1} + G_x \cdot \Delta t) + 0.04 \cdot \phi_{\text{acc}}
\end{equation}
\begin{equation}
\theta_t = 0.96 \cdot (\theta_{t-1} + G_y \cdot \Delta t) + 0.04 \cdot \theta_{\text{acc}}
\end{equation}
\begin{equation}
\psi_t = \psi_{t-1} + G_z \cdot \Delta t \quad (\text{Yaw Integration})
\end{equation}
\end{mathbox}

\subsection{Statistical Vibration \& Shock Acceleration}
To detect micro-seismic vibrations and instantaneous impact shocks, the firmware calculates real-time Root Mean Square ($\text{RMS}_{\text{vib}}$) vibration acceleration and tracks 1-second peak shock acceleration ($g$):

\begin{mathbox}
\textbf{Vibration Root Mean Square ($\text{RMS}_{\text{vib}}$):}
\begin{equation}
\text{RMS}_{\text{vib}} = \sqrt{\frac{1}{N} \sum_{i=1}^N \left(\sqrt{A_{x,i}^2 + A_{y,i}^2 + A_{z,i}^2} - 1.0\right)^2}
\end{equation}

\textbf{Peak Shock Acceleration ($g$):}
\begin{equation}
g_{\text{peak}} = \max_{1 \le i \le N} \left( \sqrt{A_{x,i}^2 + A_{y,i}^2 + A_{z,i}^2} \right)
\end{equation}
\end{mathbox}

\subsection{Edge Anomaly Engine \& Event Persistence State Machine}
The firmware classifies system health into three primary operational states (\texttt{SYS\_NORMAL}, \texttt{SYS\_WARNING}, \texttt{SYS\_CRITICAL}) regulated by an event persistence hysteresis timer ($1500\,\text{ms}$) to prevent transient false alarms:

\subsection{Adaptive Rate Controller \& Health Index Score}
\begin{itemize}[leftmargin=*]
    \item \textbf{Adaptive Telemetry Rate Controller}: Automatically scales telemetry dispatch intervals from a baseline $1000\,\text{ms}$ down to $100\,\text{ms}$ ($10\,\text{Hz}$ high-speed burst mode) upon anomaly detection, returning to $1000\,\text{ms}$ when static equilibrium resumes.
    \item \textbf{Node Health Index Score (0--100\%)}: Computed dynamically:
    \begin{equation}
    H = 100 - (15 \cdot S_{\text{I2C\_err}}) - (25 \cdot S_{\text{IMU\_off}}) - (20 \cdot S_{\text{ADC\_sat}}) - \left(\text{clamp}\left(\frac{\text{Tilt}}{5.0}, 0, 1\right) \cdot 40\right)
    \end{equation}
\end{itemize}

\section{GeoNail OS Web Visualizer \& 1:1 Scale Digital Twin (\texttt{sih-3d-visualizer})}

The frontend application is built on React 18, TypeScript, Tailwind CSS, Lucide icons, and Three.js / React Three Fiber, providing interactive 3D CAD modeling and an immersive 1:1 real-world scale minefield digital twin.

\subsection{Direct Browser-to-Hardware Connectivity}
Using modern Web APIs, operators can connect physical GeoNail probes directly inside any browser without installing external software drivers:
\begin{itemize}[leftmargin=*]
    \item \textbf{Web Serial API}: Connects directly to ESP32 USB COM ports at 115200 baud, parsing incoming JSON streams in real-time.
    \item \textbf{Web Bluetooth API}: Connects over BLE GATT notifications, binding live telemetry directly to React state handlers.
\end{itemize}

\subsection{3D CAD Viewer Page Specifications}
\begin{itemize}[leftmargin=*]
    \item \textbf{3-Axis Orientation Reactivity}: Three.js 3D assembly mesh updates rotational Euler angles $(\phi, \theta, \psi)$ continuously from sensor telemetry.
    \item \textbf{Transparent X-Ray Mode}: Toggleable translucent shell material (\texttt{opacity: 0.38}, \texttt{transparent: true}), exposing internal battery, M5Stack Core board, magnetometer array, and telescoping spike rod.
    \item \textbf{Locked Cap Default State (\texttt{attachStep = 5})}: Displays top protective cap securely seated and locked onto shoulder pins.
    \item \textbf{Engineering White Grid Aesthetics}: Crisp \texttt{\#f8fafc} background with a high-precision 20px/100px engineering blueprint floor grid.
    \item \textbf{Multi-Preset Camera Control Toolbar}: One-click view switches (**ISO**, **FRONT**, **TOP**, **SIDE**, **SPIKE TIP**, **360° ROTATE**, and **RESET**).
\end{itemize}
